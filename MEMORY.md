# Memory

Long-term, core facts that should always stay in active context. Keep this short — it is loaded on every session via the `@MEMORY.md` reference in `CLAUDE.md`.

## About

-   This is a flat-Markdown "second brain": plain `.md` files in `notes/`, `people/`, and `projects/`, indexed by the root `CLAUDE.md`.
-   No note-taking app, no database. Everything is a text file on disk.

## Standing preferences

-   One topic per file. Lowercase, hyphenated filenames.
-   New durable facts go here; situational status goes in `projects/`; reference material goes in `notes/`; contacts go in `people/`.
